38 ?- house = house.
true.
reason: Identical match.

39 ?- house = abc.
false.
reason: The two elements are not the same.  

40 ?- edge(a,b) = edge(C,b).
C = a.
reason: Match because both have the same name & number of arguments (a unifies C, b matches b).

41 ?- edge(a,d) = edge(C,B).
C = a,
B = d.
reason: Same structure ( C & B unify with a & respectivly).

42 ?- edge(C,B) = edge(a,d).
C = a,
B = d.
reason: Variables will unify with any terms.

43 ?-  edge(A,f(g,h)) = edge(a,B).
A = a,
B = f(g, h).
reason: A unifies with a, B unifies with whole f(g,h).

44 ?- edge(A,A) = edge(b,c).
false.
reason: same variable appears twice with different values.

45 ?-  edge(A,A) = edge(b,b).
A = b.
reason: same variable appears twice with same value.

46 ?- A = B, B = f.
A = B, B = f.
reason: both variables have 'share' the same value 'f'.

47 ?- A = B, B = f, A = e.
false.
reason: A unifies 'e' and B unifies 'f', not same value.
